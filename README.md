# Cybergraphman

## Uso académico y de investigación
Este repositorio tiene fines exclusivamente educativos, científicos y de investigación en ciberseguridad.
Las prácticas, pruebas y demostraciones documentadas en este repositorio han sido realizadas en entornos controlados de laboratorios con equipos propios o expresamente autorizados.
Quien tenga acceso a este contenido deberá utilizarlo únicamente sobre sistemas, redes o dispositivos propios o para los que cuente con autorización expresa. Cualquier uso fuera de este contexto será responsabilidad exclusiva de quien lo realice.
